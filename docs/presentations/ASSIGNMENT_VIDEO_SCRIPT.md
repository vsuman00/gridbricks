# Assignment video: recording plan and spoken script

Target runtime: **9 minutes 20 seconds**. Part 1 is 4 minutes 25 seconds; Part 2 is 4 minutes 55 seconds. The assignment asks for a client pitch followed by a technical-lead walkthrough, each with an initial overview no longer than five minutes. Rehearse against the deployed production app and trim pauses to stay below ten minutes. This is a script, not evidence that a video has been recorded or uploaded.

## Create and send the video

1. Finish the [Vercel release checks](../ASSIGNMENT_AUDIT.md#vercel-and-docker-delivery-path) first. Use the reviewed live Elexon January snapshot for the recording. Keep the synthetic fixture out of the client result. Open the production URL signed out and confirm the rows, CSV, source details and browser layout before recording.
2. Prepare three tabs: the production app, the public GitHub repo, and the README/architecture or test evidence. Set the app to Decision, 15 January 2026, 09:00 UK. Have a terminal ready only for the Docker build and check you have actually run. Record the screen and microphone in a quiet setting. Hide account details and notifications. Use the app's browser zoom so chart labels and timestamps remain legible.
3. Record the two parts in one take or edit them into one video. Show each action as it is described; keep the cursor on the selected date, cutoff, publication time, metrics and code path. Do not claim a hosted Docker test if it has not passed. Check the final duration and listen once for clipped audio or unreadable text.
4. Upload the file in [YouTube Studio](https://studio.youtube.com/) and set Visibility to **Unlisted**. [YouTube's help page](https://support.google.com/youtube/answer/157177) explains where to change visibility. Copy the watch URL, open it in a private window and confirm playback without signing in.
5. Open the public GitHub and production Vercel URLs in the same private window. Add the production URL to the README. Enter the three verified links in [the assignment form](https://forms.cloud.microsoft/r/Ljmf1aWESK) and submit. The form link came from the brief; its contents were not accessible to the web-reading tool during the audit, so check its exact fields in your browser.

The saved January snapshot has 744 expected hourly forecast targets and 744 matched comparisons at this demo cutoff. It reports MAE, RMSE and signed bias in MW, plus coverage and daily detail. The 09:30 cutoff is a configurable demo assumption, not a confirmed buying rule.” |
